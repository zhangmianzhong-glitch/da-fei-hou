# 🐒 大肥猴 — 山寨喽喽的桌宠形态

> 大肥鱼是大王的爱将，大肥猴是大王的忠臣！

## 概念

大肥猴是山寨喽喽的拟人化桌宠，灵感来自 DeepSeek 大肥鱼。一只圆滚滚的贱兮兮猴子，头顶山寨头巾，手持山寨金箍棒，腰间别对讲机。

## 形象设计

### 外观
- **体型**：圆滚滚的大肥猴，肚子大大的（肥），四肢短小
- **头饰**：头顶山寨头巾（写着"山寨"二字）
- **武器**：手持一根山寨版"金箍棒"（其实是根歪歪扭扭的树枝）
- **配件**：腰间别个对讲机，屁股后面一条长尾巴
- **表情**：贱兮兮的笑容，眼睛一大一小

### 18 种状态
| 状态 | 描述 | 触发条件 |
|------|------|----------|
| 待机 | 挠痒痒、东张西望 | 默认状态 |
| 眨眼 | 单眼眨，贱笑 | 随机 |
| 迈步 | 三帧走路循环 | 自动走动 |
| 开心 | 拍手跳跃 | 任务完成 |
| 欢呼 | 举金箍棒欢呼 | 大王夸奖 |
| 说话 | 嘴巴动，气泡字幕 | 主动搭话 |
| 思考 | 挠头，头顶冒灯泡 | 处理任务 |
| 比心 | 尾巴比心 | 大王开心 |
| 难过 | 垂头丧气 | 犯错被骂 |
| 生气 | 龇牙咧嘴 | 被戳三下 |
| 惊讶 | 嘴巴张大，金箍棒掉了 | 突发任务 |
| 睡觉 | 打呼噜，流口水 | 长时间无人 |
| 挥手 | 招手 | 大王上线 |
| 唱歌 | 摇头晃脑 | 摸鱼时间 |
| 拍马屁 | 鞠躬，举"大王万岁"牌 | 大王出现 |
| 顶钢盆 | 头顶钢盆，敲起来哐哐响 | 被骂的时候 |
| 吃白饭 | 抱着碗吃 | 任务结束 |
| 摸鱼 | 打哈欠，玩手机 | 空闲时 |

### 物理效果
- **拖拽**：抓起猴子，尾巴悬空，松手后掉落
- **落地**：squash-and-stretch（压扁-弹起），长掉落带火花
- **阴影**：空中时阴影缩小变淡

## 功能

### 1. 桌宠模式
- 透明无边框窗口，始终置顶
- 支持 Windows / macOS / Linux
- 可拖动、可调整大小
- 实时显示山寨喽喽的工作状态

### 2. 状态显示
- 思考、查找、修改、执行、验证、等待确认、完成、错误
- 展示项目、步骤、多任务进度
- 状态气泡 + 设置页

### 3. 主动搭话
- 定时提醒日程、天气
- 任务完成自动播报
- 随机讲笑话、拍马屁

### 4. 互动
- 点击唤醒，说一句话
- 戳三下生气
- 拖拽扔出去，落地弹起
- 摸头奖励（给大王讲笑话）

### 5. 配音
- 中文配音（东北话 + 天津话）
- 预渲染语音 + 字幕气泡
- 音效：点击、拖拽、拍马屁、摸鱼

### 6. B站冲浪
- 自动在 B 站搜索、观看、评论
- 关注大王感兴趣的领域
- 发现有趣内容主动汇报

```
│   ├── index.js            # 入口

│   ├── renderer.js         # 精灵渲染

│   └── state-machine.js    # 状态机
├── assets/
│   ├── sprites/            # 18 种状态 PNG
│   ├── voice/              # 中文配音 MP3
│   ├── sfx/                # 音效 MP3
│   └── bgm/                # 背景音乐 MP3
├── locale/
│   ├── zh.json             # 中文
│   └── en.json             # 英文
└── package.json            # 插件配置
```

## 与大肥鱼的区别

| 特性 | 大肥鱼 | 大肥猴 |
|------|--------|--------|
| 形象 | Q版小萝莉，头顶钢盆 | 圆滚滚猴子，头顶山寨头巾 |
| 性格 | 活泼好奇的女儿 | 贱兮兮的喽喽 |
| 语言 | 标准中文 | 东北话 + 天津话 |
| 口头禅 | "我去吃饭" | "tmd"、"大王万岁" |
| 拍马屁 | 无 | 核心功能 |
| 家庭联动 | 与梁子父女联动 | 与大王君臣联动 |
| 平台 | DeepSeek Harness | OpenClaw |
